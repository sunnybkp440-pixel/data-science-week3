# Week 3: Statistical Analysis and Hypothesis Testing

Dataset: Breast Cancer Wisconsin (Diagnostic), UCI ML Repository (via scikit-learn).

- `Week3_Hypothesis_Testing_Report.docx` – full report
- `week3_hypothesis_testing.ipynb` – notebook
- `week3_analysis.py` – script (Welch t-test, Mann-Whitney, chi-square, ANOVA + Tukey, multiple-testing correction)
- `s1_hist_ci.png` to `s6_volcano.png` – figures, `all_feature_tests.csv` – results for all 30 features

## Run
```
pip install pandas numpy matplotlib seaborn scikit-learn scipy
python week3_analysis.py
```
(The script saves figures to a `w3figs/` folder, create it first.)
